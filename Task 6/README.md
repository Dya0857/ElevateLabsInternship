# Task 6: Create a Strong Password and Evaluate Its Strength

## ✅ Objective
Understand what makes a password strong and test it using password strength tools.

---

## 🛠 Tools Used
- [Password Meter](https://passwordmeter.com)

---

## ✅ Steps Performed
1. **Created multiple passwords** with different complexity levels:
   - Simple password (e.g., `password`)
   - Medium complexity (e.g., `sheher234`)
   - Strong password (e.g., `zelenskySays0`)
   - Very strong password (e.g., `zelenskySays@123#90`)
2. **Tested each password** on [passwordmeter.com](https://passwordmeter.com).
3. **Recorded scores and feedback** for each password.
4. **Analyzed results** to identify best practices for strong passwords.
5. **Researched common password attacks** and the importance of complexity.
6. **Documented findings** in the `Task 6.pdf` file.

---

## 📦 Deliverables
- `Task 6.pdf` – Contains:
  - Password test results
  - Best practices learned
  - Common password attacks
  - Explanation of password complexity and security impact
  - screenshots/ – Screenshots of password strength tests

---

## ✅ Key Learnings
- Longer passwords with mixed characters significantly improve security.
- Avoid dictionary words, patterns, and reused passwords.
- Password managers and 2FA add additional layers of protection.
