# Task 7: Identify and Remove Suspicious Browser Extensions

## ✅ Objective
Identify potentially harmful browser extensions and remove them to enhance security.

---

## 🛠 Tools Used
- Google Chrome (chrome://extensions/)
- Online resources for checking extension reputation

---

## ✅ Steps Performed
1. Opened Chrome Extensions page.
2. Reviewed all installed extensions for suspicious behavior.
3. Checked permissions and user reviews.
4. Verified that all installed extensions are from trusted sources.
5. Researched risks of malicious extensions.
6. Documented findings and best practices.

---

## 📦 Deliverables
- `Task 7.pdf` – Includes:
  - Findings
  - Risks of malicious extensions
  - Best practices
- `screenshots/` – Proof of extension review process

---

## ✅ Key Learnings
- Malicious extensions can steal credentials, track activity, inject ads, and install malware.
- Regular review and removal of unused extensions are critical for security.
- Always check permissions and reviews before installing any extension.
